## 2. DeepSeek Harness (dsh) ecosystem — evaluation, benchmarks, cost, trajectories

Context: `deepseek-ai/deepseek-harness` (MIT, 210,896★, created 2026-08-13, latest tag `dsh-v0.1.2-rc.1` 2026-09-03) https://github.com/deepseek-ai/deepseek-harness. Everything below was created after 2026-06-01 (nearly all after 08-13).

**Official repo — no eval/A-B tooling.**
- `BENCHMARK.md` is one paragraph: use the Python SDK `jsonrpc-agent` minimal variant with separate workspaces and session IDs https://github.com/deepseek-ai/deepseek-harness/blob/master/BENCHMARK.md. ## 6. What none of them do (updated 2026-09-04)

1. **Interleaved AB/BA paired runs of two live harness configs inside a container sandbox with paired statistics.** Only muou000/dsh-eval alternates AB/BA with Wilson intervals, but it runs as a local process ("untrusted candidates must go to a container or VM provided by an external platform") and its token/cost gate fails closed; skill-eval-harness has paired significance but no interleaving statement, no container, skills only; evalshift has the statistics but replays captured suites on two models rather than running agent configurations. Sources: §2, §1A, §1C.
2. **One-variable enforcement on the compared configs.** No tool diffs the two composed configurations and refuses a comparison that changes more than one component; Harbor's matrix and coder_eval's experiment layer compare whatever you ran. (Harbor compare.tsx; coder_eval README.)
3. **Cache-aware, time-of-day-priced cost per trial.** Inspect, Harbor and promptfoo now record cache read/write tokens, but price with static tables; Harbor-Index "reconstructed [cost] from official API pricing"; dsh-cost-meter knows DeepSeek's peak/off-peak windows but only for live sessions. No eval tool reprices each call at the tariff in force at that minute or reports cache-hit share as an outcome metric next to pass rate.
4. **Verifier self-check for custom scenario suites.** Oracle + nop validation exists only inside the Terminal-Bench PR pipeline and Harbor-Index; lemans has an oracle but no nop; evalmut/acyclic-eval mutation-test graders but not agent task verifiers; none of the plugin-A/B tools (caliper, skilldiff, coder_eval, the dsh evaluators) proves its verifiers reject an untouched workspace and accept the reference before spending model budget.
5. **Noise-floor (A/A) runs as a first-class mode.** ClawBench decomposes seed noise post hoc and keen-touchstone prints a "lever" note; no A/B tool runs A/A by default or reports the noise floor next to the A/B interval.
6. **Regression-first gating that reports cost only on trials both arms passed.** skilldiff (`--exit-on-loss`), BiBoyang (`PASS/WARN/FAIL`) and muou (`--require-pass`) gate on outcomes; cost/quality trade-offs are reported unconditionally (caliper, skill-eval-harness lift-per-dollar) rather than conditioned on matched passes.
7. **Paired-trial trace diff.** Braintrust diff mode (hosted, dataset rows) and dsh-dual-model-eval (interactive, no batch) are the only side-by-side trajectory views; Harbor's compare is a reward matrix; Inspect, promptfoo, atif-lens, agent-trajectory and the dsh Trajectory tab show one trajectory at a time.
8. **dsh loop/context/memory-level components.** Community dsh evaluators target plugins (hccccc, BiBoyang, muou, dsheval) or static safety; only cyijun/dsh-long-compaction-eval A/Bs a loop-level component (compaction), and only via Harbor ACP. The official repo ships replay snapshots and a minimal-mode benchmark note, no eval harness (§2).
9. **Token-accounting correctness.** token-accounting-conformance shows six trackers disagreeing 2×–8× on the same transcripts and that DSH writes every usage sample twice; no eval tool documents which invariants its ledger satisfies.
10. **CI exit codes + statistics + trace viewer in one open-source package.** Every tool has at most two of the three: skill-eval-harness (stats + viewer, JUnit but no regression exit semantics stated), evalshift (stats + exit status, model-only), Tracely (exit + viewer, replay-only), Inspect (viewer + `ci()`, no exit-on-regression), Harbor (viewer, no stats).
